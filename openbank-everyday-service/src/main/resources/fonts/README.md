# Bundled fonts

`DejaVuSans.ttf` (copied from openbank-document-service) is embedded, as a subset, into the
payments-export PDFs. It replaces the Standard-14 Helvetica base font, which is WinAnsiEncoding
(CP1252) and cannot encode Czech or Bulgarian text (ř, ě, Cyrillic).

DejaVu Fonts are distributed under a permissive Bitstream Vera / Arev license (free to use, embed
and redistribute, including in commercial and public projects). Full text:
